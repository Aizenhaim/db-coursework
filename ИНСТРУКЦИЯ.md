# Инструкция: как сделать скриншоты и оформить курсовую

---

## ЧАСТЬ 1. Установка программ (если ещё не установлены)

### 1.1 MySQL + MySQL Workbench
1. Зайди на https://dev.mysql.com/downloads/installer/
2. Скачай **MySQL Installer for Windows** (полный, ~450 МБ)
3. При установке выбери **Developer Default** — установится и сервер MySQL, и Workbench
4. Запомни пароль root — он понадобится для подключения
5. После установки запусти **MySQL Workbench**

### 1.2 Oracle SQL Developer Data Modeler (для ER-диаграмм)
1. Зайди на https://www.oracle.com/tools/downloads/sql-developer-data-modeler-downloads.html
2. Скачай бесплатно (нужна регистрация на Oracle)
3. Распакуй архив, запусти `datamodeler.exe`
4. Java устанавливается вместе — отдельно ничего не нужно

---

## ЧАСТЬ 2. Создание базы данных (MySQL Workbench)

### Шаг 1. Подключиться к серверу
1. Запусти MySQL Workbench
2. В главном окне нажми на **Local instance MySQL** (или создай новое подключение с хостом `127.0.0.1`, портом `3306`, пользователем `root`)
3. Введи пароль root

### Шаг 2. Запустить schema.sql (создание таблиц)
1. Меню **File → Open SQL Script**
2. Найди файл `db/schema.sql` и открой
3. Нажми **Ctrl+Shift+Enter** (или кнопку «молния» ⚡ вверху) — выполнить весь скрипт
4. В нижней панели **Output** должны появиться зелёные галочки
5. В панели **Navigator** слева появится база `airline_tickets` с 9 таблицами

### Шаг 3. Запустить data.sql (тестовые данные)
1. **File → Open SQL Script** → открой `db/data.sql`
2. Нажми **Ctrl+Shift+Enter**
3. Убедись, что ошибок нет (всё зелёное)

## ЧАСТЬ 3. Скриншоты для курсовой

> **Правило:** каждый скриншот должен содержать:
> - SQL-код или команду
> - Результат выполнения (внизу)
> - Элементы интерфейса Workbench (панели, кнопки)
> - Для Рис. 3–4: в панели Navigator слева должны быть видны таблицы базы

---

### РИС. 3 — Скриншот DDL (CREATE TABLE airline + airport)

1. Открой `schema.sql`
2. Выдели мышью только блок с `CREATE TABLE airline` и `CREATE TABLE airport` (первые две таблицы)
3. Нажми **Ctrl+Enter** — выполнить выделенное (таблицы уже созданы, но ошибки DROP IF NOT EXISTS нет)

   > Если будет ошибка «already exists» — это нормально, скриншот делай всё равно

4. В Navigator слева раскрой `airline_tickets → Tables` — видны все таблицы → **обведи их рамкой** (в Paint или любом редакторе)
5. Сделай скриншот (**Win+Shift+S** или **PrintScreen**)

## ЧАСТЬ 4. ER-диаграммы в Oracle SQL Developer Data Modeler

### РИС. 1 — Концептуальная ER-модель

1. Запусти **Oracle SQL Developer Data Modeler**
2. **File → New** → выбери **Data Modeler Design**
3. Слева в дереве раскрой **Logical Model**
4. Двойной клик на **Logical Model** → откроется диаграмма
5. На панели инструментов выбери **New Entity** (прямоугольник)
6. Нарисуй 9 сущностей, кликая на диаграмме:
   - АВИАКОМПАНИЯ
   - АЭРОПОРТ
   - САМОЛЁТ
   - МАРШРУТ
   - КЛАСС ОБСЛУЖИВАНИЯ
   - РЕЙС
   - ТАРИФ
   - ПАССАЖИР
   - БИЛЕТ
7. Двойной клик на каждой сущности → вкладка **General**: вписать логическое имя (по-русски), Preferred Abbreviation (по-английски, например AIRLINE)
8. Вкладка **Attributes** → добавь все атрибуты из таблиц 1–9 курсовой (логическое имя, тип, PK/AK/Mandatory)
9. Инструмент **New Relationship** (стрелка) → нарисуй 10 связей между сущностями согласно таблице 11 курсовой
10. Для каждой связи двойной клик → укажи мощность (Cardinality) и обязательность (Optionality)
11. Выровняй сущности красиво на диаграмме
12. **File → Export → To Image** (или **Print to PDF**) → сохрани как PNG
13. Вставь в курсовую на место `[ВСТАВИТЬ РИС. 1]`

### РИС. 2 — Физическая (даталогическая) ER-модель

**Вариант А — автоматически из концептуальной:**

1. В Data Modeler в дереве слева → правый клик на **Relational Model** → **Engineer to Relational Model**
2. Нажми **Engineer** — автоматически создастся физическая модель на основе логической
3. В дереве слева открой **Relational Model → Relational_1** — откроется диаграмма с таблицами и внешними ключами
4. Сохрани как изображение

**Вариант Б — импорт из MySQL:**

1. В Data Modeler: **File → Import → Data Dictionary**
2. Выбери тип подключения **MySQL**
3. Укажи: Host `127.0.0.1`, Port `3306`, User `root`, Password (свой), Database `airline_tickets`
4. Выбери все таблицы → **Finish**
5. Физическая модель построится автоматически со всеми таблицами и связями

## ЧАСТЬ 5. Оформление в Microsoft Word

### Шаги по порядку:

1. **Открой** `coursework.md` любым текстовым редактором (Блокнот, VS Code, Notepad++)
2. **Выдели всё** (Ctrl+A) → **Скопируй** (Ctrl+C)
3. **Открой Word** → создай новый документ → **Вставь** (Ctrl+V)

### Настрой параметры страницы:
- **Макет → Поля → Настраиваемые поля:**
  - Верхнее: 2 см
  - Нижнее: 2 см
  - Левое: 3 см
  - Правое: 1,5 см

### Настрой шрифт (выдели весь текст Ctrl+A):
- Шрифт: **Times New Roman**
- Размер: **12**
- Межстрочный интервал: **1,5**
- Выравнивание: **По ширине**
- Абзацный отступ: **1 см** (Главная → Абзац → Первая строка → 1 см)

### Настрой заголовки:
- Главы («ГЛАВА 1.» и т.д.) → стиль **Заголовок 1**, по центру, жирный, 14пт
- Разделы (1.1, 1.2 и т.д.) → стиль **Заголовок 2**, жирный, 12пт
- Подразделы → стиль **Заголовок 3**, жирный, 12пт

### Нумерация страниц:
- **Вставка → Номер страницы → Внизу страницы → По центру**
- Титульный лист и содержание — без номера (раздел **Разные нечётные и чётные**, убери нумерацию)

### Таблицы:
- Над каждой таблицей: «Таблица N — Название» (по центру, без точки)
- Шрифт внутри таблиц: 12пт, одинарный интервал

### Рисунки (скриншоты и диаграммы):
1. Удали текст `[ВСТАВИТЬ РИС. N — ...]`
2. **Вставка → Рисунок → Это устройство** → выбери нужный скриншот
3. Под рисунком вставь подпись: «Рисунок N — Название»
4. Выровняй рисунок по центру

### Содержание:
- В начале документа (после титульного листа) установи курсор
- **Ссылки → Оглавление → Автособираемое оглавление 1**

### Приложения:
- Код в приложениях — шрифт **Courier New**, размер **10**, одинарный интервал
